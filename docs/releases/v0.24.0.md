# Patch 0.24.0: batch 23, reframe and sharpen from pstack

Two short typed-only skills from pstack, copied word for word. Only the descriptions and the attribution lines are
ours.

## :sparkles: New

- `reframe` (planning, typed only): type `/reframe` with what you are building. You get 8 to 12 expert terms ranked by
  how much each changes what gets built, each with a real project or paper and a link it has opened, two or three
  neighboring fields that solved the same problem, what you did not mention, and your description rewritten.

## :arrow_up: Changed (buffs and nerfs)

- `sharpen` (planning, rework): replaced by upstream's newer version. Type `/sharpen` with a task. It says what a top
  professional would do that you did not ask for, the rawest material, the methods and tools, and what outside check
  would show the result is right, then rewrites your prompt. The rewrite asks the agent to prototype what an
  experiment can settle and leaves product and preference choices to you.
- `sharpen` (nerf to reach): it is typed only now, so it no longer starts from your words or from another skill. The
  old restate-and-confirm in six lines is gone.
- `agent-friendly-audit` and `which-skill`: they tell you to type `/sharpen` instead of offering to run it.
- `which-skill`: a router row for `reframe`.
