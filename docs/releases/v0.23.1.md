# Patch 0.23.1: between batches, plan and review agents at high effort

The agents that plan and review a batch now think at high effort instead of extra high, to save usage. They still run
on every brief and every slice.

## :sparkles: New

None.

## :arrow_up: Changed (buffs and nerfs)

- `eng-lead` and `reviewer` (nerf to cost): `effort: high` instead of `xhigh`, the same as `builder`. In the last two
  batches they were about a quarter of the session's tokens.
- `lean-subagent-dev` (nerf to cost): at a generous budget the builder, the plan checker and the reviewer all get
  `high`. The table never sets `xhigh` any more. The plan check of every brief and the fresh reviewer per item stay.
- `geppetto`: roster 7. Projects that installed the roster see the new version in the audit and can update their
  copies.

## :package: Versions

- `pau-skills` 0.23.0 to 0.23.1, `agent-orchestration` 0.14.0 to 0.14.1.

## :bar_chart: Counts

- Skills: 40
- Hooks: 16
- Tests: 2,054

## :inbox_tray: What you do

- Replace: `geppetto.zip` and `lean-subagent-dev.zip`.
- In another project that has the roster in `.claude/agents/`, type `/geppetto` and let it update `eng-lead` and
  `reviewer` to roster 7. This repository's copies are already updated.

## :warning: Known issues

- Whether `high` misses things that `xhigh` would have caught is not measured yet. If a plan check or review lets a
  real problem through in the next batches, note it in that batch's "things that bit" file.
- `skill-eval`'s trigger mode still counts typed-only skills as under test.
