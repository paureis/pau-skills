# Patch 0.27.2: batch 27, three follow-ups from batch 26

Three things the last batch's reviews found: `rule-to-hook` knows the newer hook events, a roster change with no
version bump now fails a test, and the subagent watchdog reads agent folders the way Claude Code does.

## :sparkles: New

None.

## :arrow_up: Changed (buffs and nerfs)

- `rule-to-hook` (buff): HOOK-EVENTS.md has rows for seven newer events, among them `PostToolUseFailure` (remind
  Claude after a failed call), `StopFailure`, `PostCompact`, `ConfigChange` (exit 2 blocks a settings change, except
  a policy one) and `TaskCompleted`. Each row was checked against the Claude Code 2.1.332 binary. Two old rows were
  wrong and are fixed: `PreCompact` can block compaction, and `SessionStart` also fires on a fork.
- `subagent-watchdog` (buff): an agent of your own counts as read-only in more cases, the same ones where Claude Code
  loads it: definitions in subfolders or behind links, and a `tools: [Read, Grep` list with no closing bracket. A
  file with no description is skipped, since Claude Code drops it. A type defined twice is read-only only when both
  definitions are. Fixes the known issue from 0.27.1.
- Repository only: a test now fails when a roster agent changes and the roster number does not go up.
