# Patch 0.27.0: batch 25, a wizard for the steps only you can do

When the agent hits a step only you can do, such as creating an API key or setting a CI secret, it now hands you one
command that walks you through it and checks each step, instead of a paragraph that scrolls away.

## :sparkles: New

- `wizard` (session-discipline): the agent writes a short steps file and gives you a `run` command for your own
  terminal. It shows one step at a time, opens the page, and checks the step before it moves on (a file exists, a
  variable is set, a `.env` line has a value, a URL answers, a command exits 0). You put every value in place
  yourself; the script never asks for one and never prints or logs one. Afterwards the agent runs `status` to confirm.
  Run it again and it picks up where you stopped. Adapted from Matt Pocock's bash wizard, rewritten in Node.

## :arrow_up: Changed (buffs and nerfs)

- `which-skill`: a setup step only you can do now routes to `wizard`.

## :warning: Known issues

- A `url` check ignores `HTTPS_PROXY`, so on a network that only reaches the internet through a proxy, checks of
  outside URLs fail. Use a `command` check (for example `curl` or `gh api`) there.
- An `env` check sees only the terminal that runs the wizard. A variable set in another terminal is not seen.
- If you press Ctrl-C while a `command` check is still running, that command finishes on its own (at most 30 s).
- Query parameter names are matched loosely, so a harmless name such as `author` or `zipcode` in a URL is refused.
- Not tested on Windows: CI runs Linux and macOS.
