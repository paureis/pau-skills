# Patch 0.22.0: batch 20, typed-only skills and friction-review

Seven rituals and costly runs now wait for you to type them, a new skill hunts the friction that repeats across your
sessions, and every batch from here on ships with patch notes like these.

## :sparkles: New

- `friction-review` (session-discipline, typed): type `/friction-review` to count what keeps slowing the agent down
  across this project's last 30 sessions: searches before the first edit, reruns, failed access, big tool results,
  checks nobody runs or wires in, and "no guardrail". It proposes one fix per candidate and makes only the ones you
  pick. It reads only this repository's transcripts and redacts secrets, emails, passwords and home paths.
- Patch notes: a batch's `docs/releases/v<version>.md` becomes a GitHub Release when it merges to main. See
  `docs/RELEASES.md`.
- `handoff` Start now: on your ask and a yes, it starts the next session in the background (`claude --bg`).
- `grill-me` questionnaire: a decision you cannot answer becomes a short file for the person who can.

## :arrow_up: Changed (buffs and nerfs)

- Typed only (nerf to autostart, buff to context): `session-close`, `lean-subagent-dev`, `overnight-run`,
  `skill-eval`, `agent-friendly-audit`, `geppetto` and `launch-readiness` start only when you type them. Their
  descriptions cost no context; the others total 11,395 characters of 14,000. A skill another skill starts stays
  automatic, so `session-close` still runs the short retrospective and the handoff, and now offers the full
  `retrospective` when it finds a correction.
- The ask-first list drops from 14 skills to 9, and `which-skill` has a "Skills you type" section.
- `grill-me` asks in rounds: every question that is ready, worded so "yes" accepts the recommendation.
- `bug-fix` lists nine ways to build a check that goes red and minimises the repro one element at a time.
- `tdd` names the tautological test and asks what each test surface catches and misses.
- `to-issues` slices a wide refactor as expand and contract and names the frontier; `to-prd` allows a prototype
  snippet; both, and `improve-codebase-architecture`, read `GLOSSARY.md` as well as `CONTEXT.md`.
- `instructions-audit` weighs context load against cognitive load; `lean-subagent-dev` says what a pull request body
  holds, including one-way and two-way doors.
