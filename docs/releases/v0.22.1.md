# Patch 0.22.1: batch 21, typed skill starts counted right

The usage log now counts the skills you type. Typed starts come from Claude Code itself, under the name it resolved,
so `which-skill`'s usage report shows typed and agent starts side by side.

## :sparkles: New

None.

## :arrow_up: Changed (buffs and nerfs)

- `skill-usage` hook (buff): a typed skill is logged from the `UserPromptExpansion` event, under the name Claude Code
  resolved (`/humanizer` is logged as `anthropic-skills:humanizer`). A plugin skill typed without its prefix, a skill
  from another marketplace and a synced skill whose file is not in the usual folder are now counted. Before, typed
  starts were found by reading the prompt and looking for a `SKILL.md` in four folders, and many were dropped.
- `skill-usage` (less noise): built-ins such as `/init`, MCP prompts and your own `.claude/commands` files stay out
  of the log. The hook no longer runs on every prompt, only on typed commands and Skill tool calls.

## :package: Versions

- `pau-skills` 0.22.0 to 0.22.1, `session-discipline` 0.14.0 to 0.14.1, `pau-skills-hooks` 0.6.0 to 0.6.1.

## :inbox_tray: What you do

- No skill zip changed.
- Hooks: `claude plugin marketplace update pau-skills`, then
  `claude plugin update pau-skills-hooks@pau-skills`.
- Then, in the terminal and in the desktop app, type one skill (for example `/session-close`) and have the agent start
  another, and run `which-skill`'s usage report: each start should add one line, typed or agent.

## :warning: Known issues

- A plugin's own command, and a command in a folder the hook does not check (a parent folder, an `--add-dir` folder,
  under `CLAUDE_CONFIG_DIR`), are counted as typed skill starts.
- On a Claude Code without the `UserPromptExpansion` event, typed starts are not logged.
- Lines written before this patch undercount typed starts.
- `skill-eval`'s trigger mode still counts typed-only skills as under test.
