**Q14 what Q13 left** (`done`, twelfth batch, [pull request 55](https://github.com/paureis/pau-skills/pull/55); scope settled in decision 16: build both parts). Found by the plan check, review and cold
run of the eleventh batch ([pull request 50](https://github.com/paureis/pau-skills/pull/50)).

- **The eval's default output folder is inside the repository** (decision 16: build). `args()` in
  `evals/project-setup/run.mjs` sets `out: join(HERE, 'results')`. Claude Code loads the CLAUDE.md of every parent
  folder, so the assistant, the persona and the judge of every run with the default `--out` read this repository's
  CLAUDE.md. A replay proved it: at the same cut, the old persona prompt ended 1 of 4 with its folder inside the
  repository and 4 of 4 outside. Move the default to a folder under the system temp folder, print it at the start,
  and add a test that the default is outside the repository. The README already says to pass `--out` outside.
- **The printed cost counts the assistant only** (decision 16: build). `runScenario` adds `total_cost_usd` of the
  assistant's calls; the persona's (`askPersona`) and the judge's calls drop theirs. Add them to the total, and keep
  the parts in `summary.json`.
- Done when: each part is built test first, its tests are proven with `mutate.sh`, and the four repository checks
  pass. No paid run is needed: `replay.mjs` and the tests cover both parts without a model.
- Changed in the orchestrator's review before the build (2026-10-25), and why:
  - The default is a fresh folder per run of `run.mjs`, made with `mkdtemp` under the system temp folder, not one
    fixed folder there. `prepareRun` deletes `<out>/<scenario>` before each run, so a fixed default would delete the
    last run's transcripts, which `replay.mjs` reads. The folder is made when the run starts, not in `args()`, so
    parsing the options or importing the file makes nothing. Its path is the first line the run prints.
  - `run.mjs` refuses an `--out` inside the repository, before any model call, with a message that says why. A flag
    leaks this repository's CLAUDE.md the same way the default did, and a run costs dollars. The check resolves links
    (on macOS the temp folder sits under `/var`, a link to `/private/var`).
  - `costUsd` in `summary.json` becomes the total of the assistant's, the persona's and the judge's calls, and a new
    `costParts` keeps the three parts; the printed line shows the total and the parts. Each value is rounded once, from
    the unrounded sums. A run with `--no-judge` has a judge part of 0.
  - The cost test goes through the real turn loop and judge call with a fake `claude`, not through a sum helper alone,
    so a total that drops the persona's or the judge's calls fails it.
  - The README's cost figures from earlier runs (28 and 6.98 US dollars) say they count the assistant's calls only.
  - `evals/` is in no plugin, so nothing is bumped; `CHANGELOG.md` gets a line. `evals/project-setup/.gitignore` keeps
    `results/` for folders left from earlier runs.
- Changed during the build (plan check, review and fix round), and why:
  - The plan check built the slice in a clone and ran all 25 mutations of eng-lead's table (all caught), then found
    lines no test guarded with mutations of its own: a judge call rounded before it was added still gave the right
    total with the first fake costs, a judge run in the project folder passed a `cwd === home` check, and nothing
    tested `--baseline`, a relative `--out`, the temp-folder message, or that a refused scenario makes no folder.
    Twelve corrections went into the brief before the builder started.
  - Production rule 1 (money): the costs are summed as whole micro-dollars (`Math.round(usd * 1e6)` at the boundary)
    and rounded once to cents, half up, for the report. The parts key carries the currency: `costPartsUsd`, not
    `costParts`.
  - `args()` refuses an option with no value: with the new default, a trailing `--out` would have started a paid run
    in the temp folder.
  - The review found that the check guarded only the checkout that holds `run.mjs`: run from a worktree under
    `.claude/worktrees/`, an `--out` in the main checkout was accepted and would read its CLAUDE.md. `checkOut` now
    also refuses a folder with a `CLAUDE.md`, `CLAUDE.local.md` or `.claude/CLAUDE.md` in it or in any parent, through
    the resolved path and the real path. Eight more surviving mutations got tests in the same fix round (half-up
    rounding, a call with no cost, the assistant's sandboxed HOME, the trimmed persona reply, and four smaller ones).
  - In the end: 63 eval tests (43 before), 50 mutations through `mutate.sh`, all caught, and no folder left in the
    temp folder by any test or mutation run.
