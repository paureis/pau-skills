# Q34 rule-to-hook knows UserPromptExpansion

[Back to the backlog index](../BACKLOG.md)

**Q34 rule-to-hook knows UserPromptExpansion** (`todo`, found 2026-11-25 in Q32, after Q33 and `wizard`). The
event list `skills/guards/rule-to-hook/HOOK-EVENTS.md` has no row for `UserPromptExpansion`, which Claude Code fires
for every typed slash command that resolves (a skill, a custom command or a built-in prompt command), with
`expansion_type`, `command_name` (the resolved name), `command_args` and `command_source`. On it, stdout reaches
Claude and exit 2 blocks the expansion. MCP prompts fire it with `expansion_type` `mcp_prompt`. The payloads
recorded in Q32 are in `tests/skill-usage.helpers.mjs`.

Done when the row is there with its input fields and exit-code meaning, and the guards plugin is bumped.
