    by step, and you want to approve each change"), and asks the persona to judge "the setup is over" while it plays
    a beginner who does not know what a setup looks like. The rule moves out of the role-play: it comes first, says it

    recommended a first task, the person said which one, and the assistant's next message works on it (reads,

    runner ends on a reply that holds `[END]` anywhere, through a small exported function a test can call.

    `spanish-beginner` run at the default limit must end before turn 40. Then a replay control, persona calls only:
    the transcript of that run, cut after the assistant's first message that works on the task, goes to the base
