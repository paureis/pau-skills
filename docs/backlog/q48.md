# Q48 the Skills Bench app

[Back to the backlog index](../BACKLOG.md)

**Q48 the Skills Bench app** (`todo`, decision 39; after Q47). The localhost app in the design the owner picked, on
the Q46 engine.

- Skills: every skill in the registry, its tasks, last results, and a Run button.
- Run: pick tasks, runs per task and a cost cap; live output in a terminal pane; runs can go to the background.
- Results: the final output of a task with the skill and without it, side by side, the diff each run made, and the
  uplift with error bars.
- History: every past run, opened from the results folder.
- Settings: Claude login or API key as one toggle, the model, the cost cap.
- A side chat that asks Claude about a result, and a share button that exports a run or an experiment as one static
  HTML report anyone can open (it can also be published as a Claude artifact by hand).
