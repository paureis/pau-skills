# Q49 Skills Bench plug-ins and the first add-ons

[Back to the backlog index](../BACKLOG.md)

**Q49 Skills Bench plug-ins and the first add-ons** (`todo`, decision 39; after Q48). A small plug-in system (a panel,
a command, a results exporter), proved by add-ons that stay optional so the core needs only Node:

- Obsidian export: results into a vault in the raw, wiki and outputs layout (transcripts, a note per skill, the before
  and after deliverables). The bench never reads a vault during a test run.
- Voice: start a skill or ask about a result by voice with Whisper (github.com/openai/whisper), run locally.
- Scheduled runs: a nightly or weekly round that flags a skill whose uplift dropped.
- Later candidates: social and calendar panels, and a router such as Jev (the owner's link could not be read from the
  cloud session; read it before deciding).
