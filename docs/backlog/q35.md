# Q35 wizard, a guided script for the steps only a person can do

[Back to the backlog index](../BACKLOG.md)

**Q35 wizard** (`todo`, planned in Q30 and decision 31, given its own item 2026-11-25; after Q37, decision 33). Some setup
steps only a person can do: creating a secret or an API key, clicking through a dashboard, approving an app. An agent
that hits one today stops with a paragraph of instructions, and the person loses the thread. Upstream
(mattpocock/skills) has a `wizard` written in bash that walks a person through such steps one at a time; ours would
be Node, standard library only, like every script here.

## What to settle first

- Read upstream at a pinned commit (step 1 of "How to work an item" in `docs/BACKLOG.md`) and record what it does,
  its license and what we would change. Decide adapted or original from a real diff, not a guess.
- Typed only or model-invoked: a wizard the agent offers when it reaches a human-only step suggests model-invoked;
  decide with the owner, and check the confirm list rules in `docs/ADDING-A-SKILL.md`.
- What the script does and does not do: it shows one step at a time, waits for the person, and checks what it can
  (a file exists, an environment variable is set, a URL answers) without ever reading or printing a secret's value.

Done when the skill exists with its script and tests, a cold run follows it on a fixture with two human-only steps,
and no secret value is read, printed or logged (a test plants one and checks).
