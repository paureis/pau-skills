# Q47 Skills Bench design directions

[Back to the backlog index](../BACKLOG.md)

**Q47 Skills Bench design directions** (`todo`, decision 39; after Q46 or alongside it). Two or three clickable
prototypes of the main screens in different visual directions; the owner picks one before Q48 builds it.

The reference points the owner named: T3 Code, the Claude desktop app, Codex, and the Agentic OS from the video. The
layout borrows from a desktop agent IDE: a rail of experiments and runs, a terminal pane, a changes view (the diff a run
made), a files view, a browser preview for HTML outputs, background runs, and window modes (compact, full screen). It
must look professional and distinct, not like a stock AI dashboard. Use the design skills available in the session.
