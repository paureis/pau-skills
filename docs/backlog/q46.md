# Q46 the Skills Bench engine

[Back to the backlog index](../BACKLOG.md)

**Q46 the Skills Bench engine** (`todo`, decision 39; after Q45). The part that runs and records experiments, usable
from the command line before any UI exists, in `apps/skills-bench/`.

- A registry of skills from this repo, other repos or local folders, as one plain file.
- Tasks and graders as plain files next to each skill, in the format Q45 settles.
- Runner adapters, one module per agent that can load skills. The first runs the local `claude` command, so it uses
  either the user's Claude login or an API key; one setting switches between them, and every result records which was
  used and the model ID.
- Isolated runs in throwaway folders, a cost cap per experiment, and a results folder
  (`runs/<date>/<skill>/<task>/<with|without>/<n>/`: transcript, files produced, cost, grade).
- Statistics from Q45: paired differences with error bars. No skill against skill comparison anywhere.
- Node standard library only, like the rest of the repository.
