# Q45 Skills Bench pilot: does a skill help, with and without it

[Back to the backlog index](../BACKLOG.md)

**Q45 Skills Bench pilot** (`in progress`: the kit is built and merged on the batch branch, the paid run is under way; the owner's idea of 2026-11-28; decision 39). Before any app is built, measure
whether `tdd` and `bug-fix` change the outcome of real tasks, on the existing `skill-eval` harness.

- 5 real tasks per skill, each in its own starting folder with a code grader (tests pass, the bug is fixed). Prefer
  tasks from the owner's own sessions over invented ones.
- Each task runs with the skill and without it, 3 runs each, on one pinned model, with a cap of 10 US dollars. The
  runs use an API key, asked for through the secure form, never in chat.
- Two controls: a deliberately broken copy of one skill must score lower than the real one, and an empty skill must
  show no uplift.
- An LLM judge grades where code cannot, and its verdicts are compared with the owner's own grades on 10 runs.
- Report per task: the paired difference with a confidence interval, cost and time per run, and the judge agreement.
  Recommend the run count and budget for a full round, and the results format Q46 builds on.

Done when the report exists with real numbers, both controls behave as expected (or the report says why not), and the
results format is written down.
