The timer app prints durations with formatDuration in src/duration.js, and now people need to type them in too. Add an exported function parseDuration(text) to src/duration.js that turns typed text into a whole number of seconds:

- The text is one or more parts, each a number followed by a unit: h (hours), m (minutes) or s (seconds), in upper or lower case. "1h30m" is 5400, "2H" is 7200 and "45s" is 45.

+    throw new RangeError(`duration must be text, got ${typeof text}`);
+  }

+  if (BARE.test(trimmed)) return Math.round(Number(trimmed));
+  if (!WHOLE.test(trimmed)) {
