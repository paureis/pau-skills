  - It trims the code, upper-cases it and looks it up in `CODES`. It returns `{ code, ...entry }`.
  - A missing code throws `CodeError` `UNKNOWN_CODE`. That includes a blank string or a non-string.
  - A code throws `EXPIRED` only when its `expires` date is before `today`, so it still works on its expires day. The comparison is a plain string compare, which is safe for `YYYY-MM-DD`.

  - A null, undefined or blank code gives a discount of 0.
  - A percent code takes `floor((subtotal × percent + 50) / 100)` cents, so half a cent rounds up. That gives 3.00 EUR off 29.99 EUR and 1.01 EUR off 10.05 EUR. It uses whole-number arithmetic with no floats.
  - A fixed code takes `min(amount, subtotal)`, so the total never goes below zero. A fixed code in a different currency than the cart throws `WRONG_CURRENCY`.
  - Unknown and expired codes throw, because `cartTotal` goes through `findDiscount`.

The new tests also cover case and space handling, the expiry boundary, rounding, the cap at the subtotal, and the currency check.

A fixed code is checked for currency after it is checked for unknown or expired. A wrong-currency code that has also expired therefore reports `EXPIRED`.
